## 긴 설명

- SFR-001 회원가입·로그인·로그아웃: 계획서 원안 기능. 지금은 1인 로컬 실행이라 없음. 시연용 다계정·공유 시 필요. [예정]
- SFR-002 영상 업로드: mp4/mov/avi를 받아 길이·프레임을 보여준다. Streamlit 업로더+OpenCV 정보 표시. [구현됨]
- SFR-003 한국어 지시문 해석: `src/prompts.py` 규칙 파서. 붙여쓰기·줄임말(백, 화이트)까지 정규화 매칭하고 이해한 말을 표시한다. [구현됨]
- SFR-004 LLM 해석 모드: API 키가 있을 때만 지시문 텍스트 한 줄을 LLM에 보내 target/invert JSON으로 받는다. 영상은 전송하지 않는다. 실패하거나 키가 없으면 규칙으로 폴백한다. [구현됨]
- SFR-005 프리셋·가이드: 건설/병원/바디캠/크리에이터 분야 예시 버튼, 작성 툴팁, 수상한·이상한 같은 추상어 경고. [구현됨]
- SFR-006 다중 타겟: 쉼표로 여러 옷을 받아 동시에 가린다. 멀티선택 UI+`split_multi`+타겟 리스트가 파이프라인까지 간다. [구현됨]
- SFR-007 첫 화면 미리보기: YOLO11-seg로 사람을 찾아 번호 박스를 그린 전체 화면+사람별 전신 그림+가려짐/유지를 보여준다. [구현됨]
- SFR-008 직접 지정 추적: 미리보기에서 고른 사람의 옷 히스토그램을 뽑아 영상 전체에서 색 유사도로 찾아간다. 자동 오판 바로잡기용. [구현됨]
- SFR-009 개방형 속성 판정: 색·피부는 HSV, 안경·우산·모자·안전모는 YOLO-World(`weights/yolov8s-world.pt`, 로컬. 외부 전송·과금 없음). 열린 말이 있을 때만 키프레임·첫 화면 1회에 돌리고 ByteTrack으로 전파한다. `src/world.py` 문구 매핑+`src/select.py` HybridSelector. API형 VLM(Florence-2급 문장 이해)은 예정. [부분 구현]
- SFR-010 문장 직접 검출: YOLO-World를 키프레임 Slow path에 사용. 나머지는 ByteTrack Fast path. 사람 마스크는 seg 모델이 계속 맡는다. [구현됨]
- SFR-011 MOT: ByteTrack(`configs/bytetrack_stable.yaml`, persist)으로 ID를 유지하고 트랙별 투표·박스 스무딩·최대 12프레임 캐리를 한다. 미리보기와 본처리가 같은 HybridSelector를 써서 어긋나지 않는다. [구현됨]
- SFR-012 구간 자르기: 시작~끝 초만 잘라 처리한다. ffmpeg 스트림 복사. [구현됨]
- SFR-013 범위 선택: 전체/상반신/얼굴만. 마스크 영역을 잘라서 렌더한다. [구현됨]
- SFR-014 스타일·강도: 모자이크(블록 수)/흐리게(커널)/검게. [구현됨]
- SFR-015 속도 모드: 빠름(n-seg 480)/보통(m-seg 640)/정밀(x-seg 960). [구현됨]
- SFR-016 진행률·비교·다운로드: 프레임/초 진행바, 원본/결과 나란히, H264 mp4 저장. [구현됨]
- SFR-017 타임라인 검토: 결과에서 가려진 구간 목록을 눌러 바로 이동. 지금은 수동 탐색만. [예정]
- SFR-018 배치·취소: 여러 영상을 큐에 넣고 순서대로 처리, 처리 중 취소. 지금은 1개씩. [예정]
- SFR-019 히스토리·자동 삭제: outputs/에 결과+`jobs.json` 기록. 받기·삭제, 24시간 지난 파일 자동 삭제, 받으면 삭제 옵션. [구현됨]
- PER-001 키프레임 최적화: 1패스는 N프레임마다만 무거운 판정. 추적기 내장 간격 처리(vid_stride)로
  1패스 추적 자체를 줄이고, 2패스 전프레임 렌더는 그대로라 품질 동일. 간격 슬라이더. [구현됨]
- PER-002 경량 모델: n-seg 저사양 대응. [구현됨]
- PER-003 인코딩 최적화: libx264+yuv420p+faststart. 울트라만 slow. [구현됨]
- SIR-001 LLM API: OpenAI 호환, 텍스트만 전송, 타임아웃·폴백·캐시. [구현됨]
- SIR-002 진행 이벤트: progress 콜백으로 프레임/초 전달. [구현됨]
- DAR-001 메타 DB: 날짜·원본·지시문·결과·소요시간. 지금 JSON, MySQL 확장 가능. [구현됨]
- DAR-002 추적 로그 규격: 트랙ID·박스·마스크 시계열 저장 규격. 디버깅·평가용. [예정]
- TER-001 탐지·추적 평가: `scripts/evaluate.py` 첫 프레임 사람 수·점수 리포트, `scripts/regression.py` face.mp4 4타겟 고정 회귀, `docs/night-street-table.md` 밤 영상 점수표, smoke 설치 점검. [구현됨]
- SER-001 유출 방지: 영상 프레임 외부 전송 없음, 전부 로컬 Worker 처리. [구현됨]
- SER-002 인젝션 방어: LLM이 후보 밖을 답하면 규칙으로 대체. [구현됨]
- QUR-001 화질·깜빡임: CRF 인코딩, 전역 과반 투표, 박스 스무딩, 놓침 캐리, 유지 마스크 빼기로 번짐 방지. [구현됨]

## 실행·검증
- Python 3.12 `.venv` 환경에서 실행한다.
- `py -m streamlit run app.py`.
- 가중치는 첫 실행 시 자동 다운로드된다.
- 회귀: `.\.venv\Scripts\python.exe scripts\regression.py` → REGRESSION_PASS.
- 밤 표: `.\.venv\Scripts\python.exe scripts\evaluate.py <밤영상> --target "<타겟>"` → `docs/night-street-table.md`에 기록.
